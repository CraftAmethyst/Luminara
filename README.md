Luminara is a fork project developed based on the [Arclight](https://github.com/IzzelAliz/Arclight) server.

## Advantages over Arclight

- Distributed as a standard mod
- Supports Velocity Modern forwarding on the 1.20.1 branch
- Compatible with Adventure, MiniMessage, signed chat (signed-chat), and some commonly used Paper APIs
- Better mod and plugin compatibility

## Supported Versions

| Component | stable/Trials | stable/FeudalKings |
| --- | --- | --- |
| Minecraft | 1.20.1 | 1.21.1 |
| JDK | 17, 21 | 21, 25 |
| Forge | ≥ 47.4.0 | Not supported |
| NeoForge | Not supported | ≥ 21.1.117 |
| Fabric Loader | Not supported | ≥ 0.16.0 |
| Fabric API | Not supported | ≥ 0.115.0 |
| CraftBukkit | `v1_20_R1` | `v1_21_R1` |

## Technical Support

In general, before asking a question, please read this project's [documentation](https://lum.rimecraft.top); it will help you a lot.

If you encounter a bug while using it, or have better suggestions, you are welcome to raise them in [Issue](https://github.com/CraftAmethyst/Luminara/issues).

If a security vulnerability is involved, please report it privately in accordance with the [Security Policy](SECURITY.md). Do not publicly discuss it in group chats or directly submit a public Issue.

See the [Support Policy](SUPPORT.md) for details.
